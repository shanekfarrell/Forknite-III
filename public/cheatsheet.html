Website Layout Terms for Non-Designers

A visual layout reference guide breaking down interface structure, design mechanics, and response behaviors into plain English.

Structure

Header

The top bar of every page. Contains logo, navigation links, and sometimes a CTA button. Stays visible as you scroll on most modern sites.

Structure

Footer

The bottom bar. Contains secondary links, legal text, social icons, contact info.

Structure

Hero

The first thing visitors see. Full-width, with a headline, subheading, and CTA. Sets the tone for the whole site.

Structure

Section

A self-contained content block with its own background, padding, and purpose.

Structure

Sidebar

A narrower column running alongside main content. Common in blogs and dashboards.

Layout Mechanics

Grid

Divides the page into invisible columns and rows. Most layouts use 12 columns. Elements snap to grid positions.

Layout Mechanics

Flexbox

Aligns elements in a single direction — a row or a column. Controls spacing, order, and alignment between items.

Layout Mechanics

Container

An invisible box that limits content width and centres it on screen. Stops text stretching uncomfortably on wide monitors.

Layout Mechanics

Whitespace

Empty space with no content. Intentional, not accidental. Makes layouts feel premium and readable.

Layout Mechanics

Padding

Space inside an element, between its content and its border. Like the margin inside a picture frame.

Layout Mechanics

Margin

Space outside an element, pushing other elements away. Like the gap between picture frames on a wall.

Navigation

Navbar

Horizontal bar of navigation links, usually in the header. The primary way users move around a site.

Navigation

Hamburger Menu

The ☰ icon on mobile. Tapping reveals a hidden nav menu.

Navigation

Breadcrumb

A trail showing where you are in the site hierarchy. E.g. Home › Blog › Post Title.

Navigation

Anchor Link

A link that jumps to a specific section on the same page rather than loading a new one.

Content Blocks

Card

A boxed unit of content with an image, headline, short text, and a link or button. Like a physical index card.

Content Blocks

CTA (Call to Action)

A button or prompt telling the user what to do next. The most important element on any marketing page.

Content Blocks

Banner

A full-width strip for announcements, alerts, or promotions. Often appears above the header.

Content Blocks

Modal

A popup box that appears over the current page. The background goes dark. Requires user interaction before continuing.

Content Blocks

Tooltip

A small label appearing on hover. Used to explain icons without cluttering the layout.

Content Blocks

Carousel / Slider

Content that cycles horizontally via auto-play or arrow clicks. Common for testimonials and galleries.

Content Blocks

Accordion

A list where clicking a heading expands it to reveal content. Used for FAQs.

Content Blocks

Tab

Switches between content panels horizontally. Like browser tabs within a page section.

Responsiveness

Breakpoint

A screen width where the layout changes. Common breakpoints: mobile (480px), tablet (768px), desktop (1024px+).

Responsiveness

Mobile-first

Designing for the smallest screen first, then scaling up.

Responsiveness

Viewport

The visible area of the browser window on any given device.

Responsiveness

Responsive

A layout that automatically adapts to any screen size.

Typography & Visual

Hierarchy

The visual order of importance. Large headline → subheading → body text. Guides the eye.

Typography & Visual

Above the Fold

Everything visible before you scroll. Prime real estate. The term comes from newspapers.

Typography & Visual

Z-index

Controls which elements stack on top of others. A modal needs a high z-index to appear above everything else.
